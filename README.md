4-Bit Adder Using CMOS Logic

Project Overview

The 4-Bit CMOS Adder is a digital electronics project designed to perform binary addition using full-adder logic. It adds two 4-bit binary numbers and produces a 4-bit sum along with a carry output.

The design uses four 1-bit full-adder stages connected in a Ripple Carry Adder configuration. The project demonstrates binary arithmetic, CMOS logic concepts, circuit design and digital simulation.

Objectives

- To understand the working of a 4-bit binary adder.
- To design a full-adder circuit using logic gates.
- To implement a 4-bit adder using Verilog HDL.
- To understand CMOS logic using PMOS and NMOS transistors.
- To verify the circuit through simulation.

Circuit Description

The circuit consists of four full-adder stages connected in series.

Inputs:

- A0, A1, A2, A3 – First 4-bit binary input.
- B0, B1, B2, B3 – Second 4-bit binary input.
- Cin – Initial carry input.

Outputs:

- S0, S1, S2, S3 – Sum outputs.
- Cout – Final carry output.

Working Principle

Each full adder adds three binary inputs:

- A
- B
- Carry-in (Cin)

It produces two outputs: Sum and Carry-out.

Boolean Expressions

Sum:

S = A XOR B XOR Cin

Carry:

Cout = AB + ACin + BCin

The carry generated by one stage is passed to the next stage until the final carry output is generated.

Tools and Technologies Used

- LTspice – Circuit design and simulation.
- Verilog HDL – Digital logic implementation.
- EDA Playground – Verilog simulation.
- Icarus Verilog – HDL simulator.

Simulation Results

The following test cases were used to verify the adder operation:

Input A| Input B| Sum| Carry
0011 (3)| 0101 (5)| 1000 (8)| 0
1111 (15)| 0001 (1)| 0000 (0)| 1

The simulation confirms the expected addition results, including carry generation.

Conclusion

The 4-Bit Adder project demonstrates the working of binary addition using cascaded full-adder stages. The Verilog implementation and simulation help verify the addition and carry-generation operations. The project also provides practical exposure to CMOS logic concepts and digital circuit design.
